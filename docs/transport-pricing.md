# 城际交通票价与席别规则

## 目标

高铁、火车、飞机三个入口不再各自让 LLM 拍一个票价，而是统一走
`backend/app/services/transport_pricing.py` 的同一套里程公式。这样同一段距离、
同一席别在不同交通方式下只有“基准费率”不同，计价步骤完全一致，便于解释和复核。

> 这里的价格是**参考估算**，不是 12306 或航司的实时余票/实时成交价。

## 计价公式

### 1. 里程阶梯（递远递减）

以 12306 公布票价的递远递减思路，把里程拆成边际区间：

| 里程区间 | 该段费率系数 |
|---|---|
| 0–200 km | 1.00 |
| 200–500 km | 0.92 |
| 500–1000 km | 0.85 |
| 1000–2000 km | 0.78 |
| 2000 km 以上 | 0.72 |

某段基准票价：

```text
base = Σ(该段里程 × 方式基准费率 × 区间系数)
```

再套用最低票价，最后乘席别系数并取整。

### 2. 方式基准费率 / 最低票价

| 方式 | 基准费率（元/km） | 最低票价（元） | 距离修正 |
|---|---:|---:|---:|
| 高铁 | 0.46 | 30 | 直线 × 1.15 |
| 火车 | 0.15 | 10 | 直线 × 1.20 |
| 飞机 | 0.65 | 200 | 直线 × 1.00 |

高铁按 G/D 二等座公布票价的量级；火车按普速硬座量级；飞机按经济舱参考价量级。
三者使用同一个函数、同一套里程阶梯，只是基准费率不同。

### 3. 席别分类与系数（按交通方式独立）

席别不再共用一套枚举：每种交通方式使用自己的座位/舱位分类，基准席别分别为
高铁二等座、火车硬座、飞机经济舱。

#### 3.1 高铁 / 动车

| 席别 | 系数 | 对票价的影响 |
|---|---:|---|
| 二等座 | 1.00 | 基准票价 |
| 一等座 | 1.60 | 约 1.6 倍 |
| 特等座 | 2.40 | 约 2.4 倍 |
| 商务座 | 3.00 | 约 3.0 倍 |
| 无座 | 1.00 | 与二等座同价 |

#### 3.2 普速火车

| 席别 | 系数 | 对票价的影响 |
|---|---:|---|
| 硬座 | 1.00 | 基准票价 |
| 软座 | 1.50 | 约 1.5 倍 |
| 硬卧 | 1.80 | 约 1.8 倍 |
| 软卧 | 2.80 | 约 2.8 倍 |
| 高级软卧 | 4.00 | 约 4.0 倍 |
| 无座 | 1.00 | 与硬座同价 |

#### 3.3 飞机

| 舱位 | 系数 | 对票价的影响 |
|---|---:|---|
| 经济舱 | 1.00 | 基准票价 |
| 超级经济舱 | 1.30 | 约 1.3 倍 |
| 公务舱 | 2.50 | 约 2.5 倍 |
| 头等舱 | 4.00 | 约 4.0 倍 |

计算顺序：`先取整基准票价 → × 当前方式席别系数 → 再取整`。系数是参考估算，
不是 12306/航司公布的固定倍率，实际结果会因四舍五入有 1 元以内差异。

后端会把不属于当前交通方式的席别归一为默认席别：高铁 `二等座`、火车 `硬座`、
飞机 `经济舱`；自驾/长途汽车没有独立席别，返回 `None`。

## 行程与预算

- 站点序列：
  - 有出发地：`出发地 → 城市1 → … → 城市N → 出发地`，往、返各计一次；
  - 无出发地但多城市：`城市1 → … → 城市N → … → 城市1`，反程自动补齐；
  - 单城市且无出发地：没有城际段，城际预算为 0。
- 每一段独立计价后相加，得到 `intercity_ticket_total`（元/人），即往返合计。
- 该金额写入 `budget.total_inter_city_transport`，是否进入 `budget.total` 仍由
  “城际交通合并计入总预算”开关决定。
- 城际距离优先从行程景点/酒店坐标估算；缺失时调用高德地理编码，再回退内置主要城市坐标。
- 地理编码失败时保留 LLM 的城际预算，并标记 `intercity_pricing_basis=llm_estimate`。

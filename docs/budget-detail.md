# 预算明细

## 功能

- **按天查看**：`全部天数 / 第 1 天 / 第 2 天…` 筛选，列表上方显示当天项数与明细小计。
- **排序**：
  - 按游玩顺序（默认）：同一天内 交通 → 景点 → 餐饮 → 酒店；
  - 金额高低、天数升降序；
  - 自定义顺序：点击行内 ↑/↓ 后自动进入，可逐项调换位置；
  - “恢复游玩顺序”一键回到默认排序。
- **修改金额**：点击铅笔进入行内编辑，直接输入金额，回车或 ✓ 保存，✕ 取消；修改后自动重算分类小计与总计。
- **删除/复原**：保留原有删除到“待选项”和复原能力。
- **展示格式**：金额使用千分位（如 `¥1,879`）；操作列统一为上移、下移、编辑、删除四个图标。

## 开始环节的预算设置

- 定制表单的 Step 1 增加“旅游预算（选填）”：留空不限制金额，填写后规划 Prompt 会按预算约束酒店、餐饮、门票和市内交通。
- 默认城际交通单独列示，**不计入**总预算；勾选“将城际交通合并计入旅游总预算”后，总额才加上城际费用。
- 后端 `normalize_budget()` 以每日门票/酒店/餐饮明细重新汇总，再按开关决定是否加城际交通，避免 LLM 汇总口径不一致。
- 结果页总额、预算上限提示、城际交通标签和导出图使用同一口径；编辑金额后重算不会丢失开关或预算上限。
- 地点抽屉新增地点时会实时查询高德参考价格：餐饮写入当日餐饮、酒店写入住宿、景点写入门票；无可用价格时地点仍保存，但该条预算记为 0 并明确提示“未计入预算”。
- 地点增删改后后端会重算任务 JSON 的预算汇总，前端刷新后同步更新预算明细。

## 城际票价与席别

- 定制表单新增“城际席别”：按交通方式独立分类，切换交通方式时自动切换可选席别并重置为默认席别；自驾/长途汽车不显示。
  - 高铁：二等座、一等座、特等座、商务座、无座；
  - 火车：硬座、软座、硬卧、软卧、高级软卧、无座；
  - 飞机：经济舱、超级经济舱、公务舱、头等舱。
- 高铁、火车、飞机共用 `backend/app/services/transport_pricing.py` 的同一套 12306 里程阶梯公式，仅基准费率、最低票价和线路绕行系数不同。
- 席别系数（以各自基准席别为 1.0）：
  - 高铁：一等座 ×1.6、特等座 ×2.4、商务座 ×3.0、无座 ×1.0；
  - 火车：软座 ×1.5、硬卧 ×1.8、软卧 ×2.8、高级软卧 ×4.0、无座 ×1.0；
  - 飞机：超级经济舱 ×1.3、公务舱 ×2.5、头等舱 ×4.0。
- 在基准票价取整后乘席别系数，再取整；席别与交通方式不匹配时回退到该方式默认席别。
- 计价按“出发地 → 各城市 → 出发地”的往返/联程分段计算；无出发地多城市时自动补齐反程，逐段取整后相加，因此城际费用包含往、返两次；单城市且无出发地时为 0。
- 城际距离优先使用行程中景点/酒店坐标估算，缺失时用高德地理编码；地理编码失败则保留 LLM 的城际预算并标注“模型估算”。
- `Budget` 新增元数据：`intercity_transport_mode`、`intercity_seat_type`、`intercity_distance_km`、`intercity_ticket_total`、`intercity_pricing_basis`。
- 结果页在城际卡片下显示“高铁 · 商务座 · 约 ¥X/人（N km，按12306里程规则估算）”；预算编辑重算不会丢失这些元数据。

## 实现约束

- 预算条目由行程数据派生，`BudgetDetailItem.id` 稳定标识条目；
- `budgetCustomOrder` 保存自定义顺序；条目增删时自动清理/补齐，不丢顺序；
- 调换只在同一天内进行，避免把第 1 天的项目移动到第 2 天；
- 修改交通费用时仍按全局交通总额分天均摊，这是既有预算模型；
- 修改金额后写回行程对象与 `sessionStorage`，并调用 `recalculateBudgetTotals`。
